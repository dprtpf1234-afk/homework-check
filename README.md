# 📮 과제물·가정통신문 수합 웹앱

학생은 교실 태블릿에서 **이름 → 제출물 선택 → 제출**,
교사는 관리자 페이지에서 **학생 × 과제 현황표(제출 = ●)** 를 보고 과제를 추가·삭제합니다.
모든 기록은 **구글 스프레드시트**에 쌓이며, 파일 → 다운로드 → Excel(.xlsx)로 받을 수 있습니다.

```
GitHub Pages (화면)                     Google Apps Script (API)          Google 스프레드시트 (DB)
 index.html  학생 제출 화면   ──fetch──▶  apps-script/Code.gs   ──────▶  학생명단 / 과제목록 / 제출기록
 admin.html  관리자 페이지
```

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 학생 제출 화면 (태블릿용). **오른쪽 위 시계를 누르면** 관리자 비밀번호 키패드 |
| `admin.html` | 관리자 페이지 — 제출 현황 / 과제 관리 / 학생 명단 / 설정·연동 |
| `assets/api.js` | 구글 시트 API 연결 + 연동 전 데모 모드 |
| `config.js` | 제목·반 이름·연동 URL 설정 |
| `apps-script/Code.gs` | 구글 스프레드시트에 붙여넣을 서버 코드 |

## 1. GitHub Pages로 배포

1. GitHub에서 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다 (폴더 구조 그대로).
2. 저장소 **Settings → Pages → Branch: `main` / `(root)` → Save**.
3. 잠시 후 `https://<아이디>.github.io/<저장소>/` 가 학생 화면, 뒤에 `admin.html` 을 붙이면 관리자 페이지입니다.

> 연동 전에도 **데모 모드**로 바로 동작합니다 (가상 학생 20명, 그 브라우저에만 저장, 비밀번호 `1234`).

## 2. 구글 스프레드시트 연동

1. [새 스프레드시트](https://sheets.new) → **확장 프로그램 → Apps Script**
2. `apps-script/Code.gs` 내용을 붙여넣기 (관리자 페이지 › 설정의 **📋 코드 복사** 버튼 사용 가능)
3. 함수 `setup` 선택 → **▶ 실행** → 권한 허용 ("고급 → 안전하지 않은 페이지로 이동"을 눌러야 할 수 있음)
4. **배포 → 새 배포 → 웹 앱** — 실행: **나**, 액세스: **모든 사용자** → **웹 앱 URL** 복사
5. 관리자 페이지 › **🔗 구글 스프레드시트 연동** 버튼 → URL과 비밀번호(`1234`) 입력 → **연동하기**
6. 곧바로 **🔑 관리자 비밀번호 변경**에서 비밀번호를 바꾸세요.

### 태블릿도 연동하기
연동 정보는 기기마다 저장됩니다. 둘 중 하나를 고르세요.
- **기기에서**: 태블릿 학생 화면의 시계를 눌러 관리자 페이지에 들어간 뒤 설정에서 연동
- **한 번에**: `config.js` 의 `apiUrl` 에 웹 앱 URL을 적어 커밋 → 모든 기기 자동 연동

## 스프레드시트 구조

| 시트 | 열 |
|---|---|
| 학생명단 | 번호, 이름 |
| 과제목록 | 과제명, 마감일, 등록일시 |
| 제출기록 | **제출일시, 번호, 이름, 과제명**, 비고(교사가 직접 처리하면 "교사 확인") |

시트에서 직접 고쳐도 되고, 관리자 페이지에서 고쳐도 됩니다.

## 알아두기

- 같은 학생이 같은 과제를 두 번 제출해도 중복 기록되지 않습니다.
- 과제를 삭제해도 이미 쌓인 제출기록은 시트에 남습니다.
- 관리자 표의 칸을 누르면 제출 처리/취소 (종이로 직접 받았거나 학생이 잘못 누른 경우).
- 학생 화면은 제출 후 5초, 선택 중 방치 60초 뒤 자동으로 처음 화면으로 돌아갑니다.
- `Code.gs` 를 고친 뒤에는 **배포 → 배포 관리 → ✏️ → 새 버전 → 배포** (URL 유지).
- 비밀번호를 잊으면: Apps Script **프로젝트 설정 → 스크립트 속성**에서 `ADMIN_PIN` 삭제 → `1234` 로 초기화.
- 웹 앱 URL을 아는 사람은 학생 제출 요청을 보낼 수 있습니다. 관리 기능은 비밀번호로 보호됩니다(10회 틀리면 10분 잠금).
